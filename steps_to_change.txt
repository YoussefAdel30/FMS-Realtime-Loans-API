Replace the JAR, run only sql/08_add_nid_column.sql on the existing FMSUSER table, and add four blocks to the server application.yml. Do not run 01 through 07 again.

SQL
Connect as the owner:


sqlplus FMSUSER@//FMS-SCAN:1530/FMSPRD6
In 08_add_nid_column.sql, set this line before you run it:


DEFINE schema_owner = FMSUSER
That script adds NID to FMSUSER.MSISDN_ELIGIBILITY_AUDIT and creates the index IDX_MSISDN_ELIG_PAIR_TS. Run it once, before you start the new JAR.

If the table is empty, you can then run:


ALTER TABLE FMSUSER.MSISDN_ELIGIBILITY_AUDIT MODIFY (NID VARCHAR2(32 CHAR) NOT NULL);
Leave schema: FMSUSER in the YAML. Do not change it back to FMSPRD6.

YAML
Edit /app/scripts/utilities/realtime_loans_api/application.yml. Leave the directories, disk-path, JDBC settings, and schema: FMSUSER as they are.

1. Under api:, immediately after the msisdn: block, add:


  nid:
    pattern: "^[0-9]{14}$"
    min-length: 14
    max-length: 14
    description: "14-digit national id"
2. Inside api.response:, add these three lines. The block should look like this:


  response:
    eligible-value: OK
    ineligible-value: KO
    ko-reason-prefix: "Anti-fraud : "
    ko-reason-separator: ", "
    include-request-id: true
    include-msisdn: true
    include-nid: true
    include-reasons: true
    include-blacklist-version: true
include-nid, ko-reason-prefix, and ko-reason-separator are the new lines.

3. Inside api.error:, keep the two existing lines and add status-text and messages:


  error:
    include-message: validation-only
    include-path: true
    status-text:
      bad-request: "Bad Request"
      unauthorized: "Unauthorized"
      unsupported-media-type: "Unsupported Media Type"
      service-unavailable: "Service Unavailable"
      internal-server-error: "Internal Server Error"
    messages:
      msisdn-required: "msisdn is required"
      msisdn-length: "msisdn length must be between {min} and {max}"
      msisdn-pattern: "msisdn does not match the configured pattern"
      nid-required: "nid is required"
      nid-length: "nid length must be between {min} and {max}"
      nid-pattern: "nid does not match the configured pattern"
      invalid-json: "request body is not valid JSON"
      validation-failed: "request validation failed"
      field-invalid: "{field} {detail}"
      unauthorized: "A valid API key is required"
      unsupported-media-type: "Content-Type must be application/json"
      internal-error: "An unexpected error occurred"
      internal-error-detail: "{exception}"
      audit-writer-down: "Audit writer is not running"
      disk-space: "Free disk space is below monitoring.disk-space-threshold-bytes"
      audit-queue-readiness: "Audit queue utilization exceeded the readiness threshold"
      audit-rejected: "Audit pipeline did not accept the event within {timeout}ms"
      blacklist-not-loaded: "Blacklist is not loaded"
      blacklist-stale: "Blacklist snapshot {version} exceeded max age {maxAge}"
4. Under blacklist:, next to msisdn-column, add:


  nid-column: NID
Then stop the process, copy in the new msisdn-api.jar, put a blacklist CSV whose columns are MSISDN,NID,<flags> plus its .ready file into incoming, and start again.
